# Automated Ways to Convert Colors
If you have a large list of custom dark mode hex values and want to find their light mode counterparts instantly, you can use these tools:
- **Option A:** Use the Adobe Color WheelGo to the Adobe Color Wheel. Input your dark accent color hex.Switch the harmony rule to "Custom" or "Shades". Slide the node vertically straight up into the light spectrum. This modifies the color's lightness value without drifting into a completely different color family (keeping your hues aligned).
- **Option B:** Real-time UI GeneratorsPlatforms like Realtime Colors allow you to drop in a single primary palette and click an auto-generate button to immediately see how the entire layout maps between light and dark modes across real UI components.
- **Option C:** The Coolors ToggleIf you track your palettes on Coolors, you can select your 5-color dark palette, hit the menu dropdown, and select "Invert Palette" or "View Luminance".
